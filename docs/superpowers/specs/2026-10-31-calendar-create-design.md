# 日历创建任务

用户要求日历支持点击日期及滑动多个日期创建任务，并将完成代码提交到 GitHub 主分支，再通过 VPS 上的 Codex 更新 plandesk.qingyang.ai。

- 点击日期格打开创建表单，开始、结束均为当天。拖选连续日期时实时高亮，松开后预填按时间排序、包含首尾的日期区间；支持反向、跨周、跨月和触控指针。
- 表单填写任务名称，可调整日期；取消或 Escape 不创建任务。空白名称和结束早于开始不能提交。
- 保存接入已有任务 schema、写入队列、撤销和重做；继续留在日历。已有任务点击仍打开详情。键盘可聚焦日期按钮并用 Enter 创建。
- 沿用现有 React/CSS 和任务契约，不增加依赖或修改服务 API。相较点击立即写入默认任务，先填写表单可避免误触和空任务；独立的范围选择模式会增加操作，故采用直接拖选。
- 在现有干净工作目录从 origin/dev 建立 calendar-create 分支。验证后按用户最新指示快进 main，同时同步 dev；不强推。云端先检查、备份，再更新，独立核验线上资源与健康接口。
